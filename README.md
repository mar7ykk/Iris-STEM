# Аналіз текстурних особливостей райдужної оболонки ока

STEM-проєкт з комп'ютерної графіки та візуалізації.

## Мета проєкту

Дослідити текстурні особливості райдужної оболонки ока за допомогою класичних алгоритмів обробки зображень.

## Використані алгоритми

1. Вирівнювання гістограми — покращення контрастності.
2. Метод Оцу — автоматична бінаризація.
3. Оператор Собеля — виділення контурів.
4. LBP — аналіз локальної текстури.
5. GLCM — аналіз текстури за матрицею суміжності рівнів сірого.

Усі алгоритми реалізовані самостійно на Python.

## Робота програми

1. Зчитування фотографій із папки `data/images`.
2. Перетворення зображень у відтінки сірого.
3. Приблизне визначення області райдужки.
4. Застосування вибраних алгоритмів.
5. Обчислення метрик MSE, PSNR та характеристик GLCM.
6. Збереження результатів.

## Використані бібліотеки

- NumPy
- Matplotlib
- Pillow
- OpenPyXL

## Запуск

Встановлення бібліотек:

```bash
pip install -r requirements.txt
```

Запуск програми:

```bash
python main.py
```

Після запуску потрібно ввести кількість фотографій для обробки.

Налаштування алгоритмів знаходяться у файлі `config.json`.

## Результати

Оброблені зображення зберігаються в папці `results`.

Числові результати записуються у файли:
- `results/metrics.csv`
- `results/metrics.xlsx`

## Тестування

Для перевірки алгоритмів створені автоматизовані тести.

Запуск тестів:

```bash
python -m pytest tests/test_algorithms.py -v
```
